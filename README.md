# Sowderca Tap

## How do I install these formulae?

`brew install sowderca/tap/<formula>`

Or `brew tap sowderca/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sowderca/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
